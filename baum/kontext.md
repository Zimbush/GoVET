# Ein binärer Baum für Ganzzahlen mit aufsteigender Sortierung

Es soll eine Struktur in der Sprache Golang definiert werden, die einen binären Baum modelliert.

- Es gibt nur eine Sorte von Knoten.
- Ein Knoten enthält eine Ganzzahl als Inhalt.
- Ein Knoten kann keinen, einen oder zwei Kindknoten enthalten.
- Ein Blatt ist ein Knoten ohne Kinder.
- Die Anordnung der Knoten im Baum besitzt eine aufsteigende Sortierung.
- Es kann ein Knoten eingefügt werden.
- Beim Einfügen wird der Knoten an der richtigen Stelle eingefügt, so dass die lineare Ordnung erhalten bleibt.
- Doppelte Werte sind erlaubt und werden mehrfach als Knoten eingefügt.
- Das Ausbalancieren eines Baums soll möglich sein.
  - Auslesen des Baums in eine sortierte Liste.
  - Einlesen der sortierten Liste in einer geeigneten Form, so dass ein möglichst balancierter Baum entsteht.
